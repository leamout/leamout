# Enterprise deployment roadmap

Leamout Enterprise private deployments are a **future expansion**, not a
second runtime or an edition of the existing Core application.

The immediate priority is stable Leamout Cloud API, worker, media, SIP and
billing services. Private deployment packaging, identity federation,
governance, uptime SLAs and any contractual license mechanism should be
designed only when there is a concrete customer requirement.

Current Open Source grants to earlier published code are unaffected.
